# BioDermika · sitio web

Página de marca de BioDermika (Proyecto Emprendedor, UAA). Sitio estático: HTML, CSS y JavaScript sin dependencias.

- `index.html` — contenido
- `styles.css` — estilos (colores y tipografía en `:root`)
- `main.js` — animación del hero, escala de pH, copiar código
- `assets/` — logo, imágenes y clips de video

Para verlo en local: abre `index.html` o corre `python3 -m http.server`.

Publicado en Render como Static Site (publish directory: `.`, sin build command).
